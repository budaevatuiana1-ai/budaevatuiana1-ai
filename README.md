## 🤖 Будущий проект с AI-агентом

### AI-агент для подготовки структуры сайта врача или эксперта

Хочу разработать AI-агента, который будет помогать на первом этапе создания сайта для врача, эксперта или бизнеса в сфере услуг.

Сейчас подготовка проекта часто начинается с большого количества разрозненной информации: брифа, описаний услуг, старых текстов, заметок, ссылок, документов и материалов клиента.

Задача AI-агента — помочь превратить эти материалы в структурированную основу будущего сайта.

### Что получает агент

На вход можно будет передать:

- заполненный бриф;
- информацию о специалисте или компании;
- описание услуг;
- существующие тексты;
- документы и заметки;
- ссылки на сайт и социальные сети;
- информацию о целевой аудитории;
- дополнительные материалы клиента.

### Что должен делать AI-агент

1. Анализировать исходные материалы.
2. Определять основные задачи будущего сайта.
3. Выявлять недостающую информацию.
4. Структурировать услуги и ключевые смыслы.
5. Предлагать логичную структуру сайта и последовательность блоков.
6. Формировать черновики текстов для основных разделов.
7. Составлять список материалов, которые необходимо дополнительно запросить у клиента.
8. Собирать результаты в единый структурированный документ для дальнейшей работы над UX и дизайном.

### Зачем мне этот проект

Значительная часть работы над сайтом происходит ещё до начала дизайна — на этапе анализа, систематизации информации и построения структуры.

Я хочу автоматизировать часть этой подготовительной работы с помощью AI, при этом оставив финальные решения, проверку смыслов и редактуру за дизайнером.

В дальнейшем такой AI-агент может стать моим рабочим инструментом для проектов Tuiana Design и отдельным кейсом в портфолио.

**Статус проекта:** планируется к разработке 🚧
